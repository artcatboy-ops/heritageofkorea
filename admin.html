정말 게시할까요? 사이트 내용이 지금 화면의 내용으로 바뀝니다.

접근 열쇠 만드는 법 (한 번만)

  1. github.com에 로그인한 뒤 오른쪽 위 내 사진 → Settings
  2. 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. 이름은 아무거나(예: 관리화면), 기간(Expiration)은 가능한 길게
  4. Repository access에서 Only select repositories를 고르고 heritageofkorea만 선택
  5. Permissions → Repository permissions에서 Contents를 찾아 Read and write로 바꿉니다.
  6. Generate token을 누르고, 나온 긴 글자를 복사해 위 칸에 붙여 넣습니다. 이 화면은 한 번밖에 안 보이니 꼭 복사하세요.

열쇠는 이 저장소 하나만 고칠 수 있게 제한됩니다. 기간이 끝나면 같은 방법으로 새로 만드세요. 열쇠가 유출됐다고 생각되면 GitHub에서 그 토큰을 바로 삭제(Revoke)하세요.
